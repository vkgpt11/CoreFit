# Simple Exercise Counter

A minimal Android exercise interval counter built with Kotlin and Jetpack Compose.

## MVP features
- Configurable repetitions
- Configurable seconds per rep
- Configurable number of sets
- Configurable rest duration
- 3-second get-ready countdown
- Automatic exercise/rest transitions
- Voice counting with Android Text-to-Speech
- Vibration cues
- Pause/resume and stop/reset
- Keep-screen-awake during workout

## Build

The GitHub Actions workflow builds a debug APK on pushes and pull requests to `main`, and supports manual dispatch.
